# Operational evidence and Closure paths

Two complementary regressions exercise the complete participation flow.
`FullEvidenceFlowTest` uses real participant contributions for every Phase,
Proposition, edge, Receipt, Attestation and Rest. It controls only numeric Closure
values to isolate routing and action eligibility. `OperationalClosurePathTest`
uses real Closure calculations, with explicit early evidence fixtures to isolate
measurement and snapshot agreement. Neither test alone proves every possible
participation schedule will converge.

## Full seven-phase participation

| Stage | Collaboration | Expected result |
| --- | --- | --- |
| Distinguish | A creates a Signal; B instruments it; C attests it | Receipt before Attest; an ungrounded Gate cannot be classified |
| Persist | C reclassifies Signal; A and B attest the new Stance | Exact statement and proposition Receipt preserved; fresh judgments |
| Constrain | A reclassifies Stance; B and C attest Concord | Both receipt and effective attestation precede reclassification |
| Disperse | A and B create separate Signals; C instruments one | New content starts with fresh evidence |
| Mediate | B reconciles; C instruments the new Stance; A attests it | Both reconciliation parents remain; new Stance earns its own grounding |
| Bias | A reclassifies; B and C attest its Concord Write | Shared result, preserved content/evidence, reset votes; other participants unlock Order |
| Order | A legitimately Rests while fresh votes are absent; B later Commits; C Traverses that Committal | Only terminal actions; consumed expressive source removed globally |
| Next Cycle | B and C explicitly enter at the traversed/created Committal | Exact positional continuity with applicable Horizon, no teleport |

No receipt is loaded in this routing example: receipt existence permits Attest,
and loaded Reinforcement is optional weight. The tests separately verify personal
Attestation before expressive Traverse and no pre-terminal evidence actions in
Order. The two-Domain continuity regression also covers a participant traversing
a boundary commitment while its existing Cycle still belongs to the old Horizon.

## Real Closure remains authoritative

The numeric late-phase regression creates shared early structure, disperses two
Signals, reconciles a Stance, and reclassifies it at Bias. Receipt setup is explicit
for the initial reclassifications and the new Stance; those fixture operations do
not stand in for a complete participant-only Instrument path.

The new Concord retains proposition-level Receipts but none of the Stance's
Attestations or touches. Other participants attest and instrument that Concord
through Bias. Equal active-head touch counts initially produce a Cadence direction
that disagrees with Depth. Commit is absent from the schema and direct dispatch
also rejects it without changing graph or lifecycle state.

An additional participant's normal observation changes the active-head touch
distribution. In this specific fixture, Depth and Cadence then both resolve
negative and Commit becomes admissible. The sign of their average alone cannot
override this gate, and more evidence does not guarantee a particular direction.

## Commit and retained history

Commit carries the source's earned Attestations, completed Receipts and touch
history by reference. It creates no duplicate observations. Preview and execution
must agree on Depth, Cadence, Closure and retained directions. The snapshot records
the governing history, calculator version and before/after Domain. Its measurements
remain frozen if evidence is subsequently loaded or cleared.

One direct expressive source produces one Committal globally. Competing branches
remain independent. Aligned Closure permits commitment; existing Tension rules
separately determine whether a new Context Horizon opens. Commit and Committal
Traverse end Order at that exact node. Normal next-Cycle entry retains it; Rest
and genuine exhaustion preserve the existing recovery rules.
