# Receipt-backed phase flow

> **Stage 4 contract.** The approved [Tragedy/Resolution lifecycle](tragedy-resolution-target.md) governs terminal encounters and regional exhaustion. Earlier second-catastrophe descriptions are historical.

[Core invariants](core-invariants.md) govern this cycle. Domain mappings select registers; the producing phase position determines eligibility.

Producing position is necessary but does not confer traversal eligibility.
Forward movement additionally requires an explicit causal continuation from
the current Gate; recovery follows recorded ancestry backward. Commit Region,
Horizon, visible history and calculation membership never create movement edges.
No edge means no movement.

Mediate — Read and Bias — Gate may calculate regionally; only Mediate exposes
foreign Gates as reconciliation operands, with both causal edges created by
Reconcile. Bias exposes its current causal Gate. Closure, performed during
Order — Write, evaluates each local expressive Write independently. These
calculations do not relocate the Participant. Traverse means the current Gate's causal
Write continuation; Order follows only the Commit directly produced from its
current classification. Frozen successful routes retain their existing edge,
not region-wide traversal eligibility.

| Phase | Structural flow |
| --- | --- |
| 1 Distinguish | Personal Instrument acquisition at the governing Gate before fresh Variant. An admitted Instrument enables Variant or Defer. An eligible unjudged Write offers first Attestation. A personal earlier-Cycle Attestation establishes Traverse on that side. |
| 2 Persist | When fresh Variant is lawful, Prepare a causally accessible Artifact or use Instrument fallback; develop the selected Distinguish Proposition through Variant, subject to shared structural viability. |
| 3 Constrain | Reclassify a grounded, attested Persist source using one Receipt and an authored statement; attach/consume and advance atomically. |
| 4 Disperse | Choose Instrument or accessible Preparation once per exact Phase/generative opportunity when fresh Variant is lawful; earlier-Phase acquisition in the same Cycle neither fulfills nor blocks it. Retain ordinary Variant / Attest / later-Cycle Traverse rules. |
| 5 Mediate | Interpret the relationship between two eligible Disperse Propositions. The first Mediate birth for the pair determines its Region and selected temporal lineage. |
| 6 Bias | Reclassify an eligible Mediate source using a Receipt authorized for that source and an authored statement, preserving existing lineage agreement. |
| 7 Order | Existing grounded, attested, Closure-aligned Commit or established Committal Traverse. |

See [generative acquisition](generative-acquisition.md) for completion, failure and returning-Participant rules.

Ordinary Receipt availability is Commit-Region-scoped and independent of authorship, age, loading and Participant presence. Completed ordinary Instruments create one persistent Receipt. Tragedy creates its one Receipt without a fake EvidenceExecution. Only Reclassify consumes; reading is free and does not advance the Phase. Commit may retain already attached evidence without consuming it again.

At Constrain and Bias, Reclassification writes the Participant’s interpretation of the source and attaches exactly one selected Receipt. Identical source wording is permitted. Effective Attestations and phase touches start fresh. It rejects missing, consumed, foreign-Horizon or structurally invalid inputs before publishing any new target. Other historical evidence remains on its original source. Shared classifications are unique per source/destination register.

Fresh Variant admission checks personal judgments across the viable frontier and gives advancing generation at its heads priority. Distinguish and Disperse also require ordinary evidence and an effective Attestation for each existing viable Variant. Evidence may be shared or retained on its causal lineage; exact-Write Instrumentation is not required. Potential Charge does not govern this permission. Receipt consumption alone never reopens Variant. There is no Participant quota, fixed sibling cap or prior Mediate Rest requirement. Mediate still needs a second Proposition. This is the [confirmed Variant clarification](horizon-proof-variant-clarification.md).

A qualifying direct expressive Write encounter with resulting canonical Charge zero establishes the Region’s unique Tragedy and Receipt and permanently terminates that continuation. Resolution prohibits Variant and Revise throughout the Region while preserving ordinary authority on viable routes. Exhaustion follows atomically only when no lawful continuation remains; viable siblings and live committed descendants prevent it. Descendant Exhaustion closes only its corresponding route. No second catastrophe, Rest or Receipt consumption is required. Passive measurements and reads establish neither event. Recovery follows actual recorded backward lineage.
