## Conservative bound

The reference morphology is one isolated third-register node. Its WL feature
vector has three unit coordinates: the base label and the two refinement labels.
Its norm is √3.

Every node in a genuine, non-Origin first-Settlement causal morphology has an
incident edge. Therefore none has either isolated-Origin refinement label. Only
the base third-register coordinate can overlap. If that coordinate has count n,
the current vector's norm is at least n. Consequently cosine similarity is at
most 1/√3, and Shape Topology is at most `2/√3 − 1 ≈ 0.1547006`.

The current morphology includes Origin at depth zero and at least one occupied
positive-depth row. The reference has only depth zero. The zero row scores at
most +1; each subsequent occupied row scores −1. Row-balanced Cardinal Position
is therefore at most zero. This gives the loose local Correspondence bound:

```
a = ((2/√3 − 1) + 0) / 2 = 1/√3 − 1/2 ≈ 0.0773503
```

All non-Origin ancestors before C1 obey the same bound. Origin contributes +1
at most once (unique reverse BFS), with inverse-square weight at most 1/4.
The head alone has weight 1. Additional non-Origin mass cannot increase this
upper bound:

```
combined Correspondence ≤ (a + 1/4) / (1 + 1/4) ≈ 0.2618803 < 0.5
```

Seven-decimal rounding does not approach the threshold. This is a conservative
upper bound, not a claim that a legitimate morphology attains it. Branches and
Reconcile inputs do not introduce another Origin or isolated reference features.

## Consequence and scope

With first-Commit Chirality −0.5 and Closure 0, positive Tension requires
Correspondence greater than +0.5. These first-Settlement structures cannot supply
it. The first possible natural Settlement → Emergence transition therefore needs
C2 or later, with additional committed history. No particular later transition is
guaranteed.

This argument concerns a fresh first-Settlement comparison with the isolated
Origin reference. It makes no claim about later complementary-Domain references,
and changes no calculation, selection, admissibility, or transition rule.
