# Operational Commitment

Order retains local Bias-produced expressive Concord/Canon Writes. Commit selects an admissible Write; Traverse selects its own direct Committal result. Read contains Mediate-produced Stance/Frontier ancestry. Neither Instrument, Receipt Read, Replay nor Attestation is currently an Order action. Both terminal actions finish the Cycle at the exact Committal; the next Cycle continues there under its applicable Context Horizon.

Traverse follows only the Commit produced directly from the current
classification Gate. At Bias, that frozen classification is traversable only
through the exact Gate whose causal continuation produced it, subject to ordinary
prerequisites. A classification or Commit elsewhere in the same Region/Horizon
is not a destination. Successful-route continuity preserves an existing edge;
it never manufactures one. No edge means no movement.

Closure, performed during Order — Write, evaluates each local Write's own
Depth/Cadence, lineage/history and participation. It does not enumerate or compare
regional Write candidates. All local expressive Writes remain visible under their
ordinary expressive rules; Commit is an admissible subset and only each Write's
own direct Committal may be traversed. Calculation selection, phase compatibility
and visible context cannot replace causal authority from the current Gate.

`CommitmentAdmissibilityService` first requires the selected source to occupy Phase 6 / Bias in the same Domain, Horizon and Commit Region, with an active, unconsumed expressive third-register classification. Register identity alone cannot confer this position: a Phase 3 / Constrain Canon or Concord remains contextual history. See [phase positions](phase-positions.md).

It also requires a completed Receipt, an effective Attestation on the selected classification, and aligned Depth/Cadence with hysteresis. Reinforcement is an optional weight, never a hard minimum. Receipt existence does not assert that evidence is correct or that a Participant has read it.

Commit preserves the selected source's exact statement, effective judgments, referenced receipts and phase-touch history. It consumes that direct expressive source globally and records an immutable evaluation. Alternative branches remain available. Committal results accept no new Attestations, Instruments or revisions; further development uses Variants. Reading historical evidence cannot rewrite the commitment snapshot.

All grounding and judgment opportunities exist before Order. Distinguish and Mediate support Instruments on fresh Writes. Constrain and Bias reclassification require an available Horizon Receipt plus Attestation, atomically attach that Receipt and reset votes. Persist develops structure through Variant. Existing classifications are shared, avoiding duplicate source/register results. Bias compares a head with its own causal ancestors excluding itself, not the region's other Stances.

A fresh classification can legitimately require Rest before Commit becomes available. `FullEvidenceFlowTest` exercises three participants through all seven phases with real contributions, receipt-first gating, evidence-preserving reclassification, reconciliation, Bias, Rest, zero-loaded-reinforcement Commit and Committal Traverse. Closure admissibility is isolated in that routing test; `OperationalClosurePathTest` also completes the cycle using the actual numeric Closure calculator. The measurement and hysteresis suites verify its axes independently. PostgreSQL competing-writer tests cover duplicate classifications and commitments.
