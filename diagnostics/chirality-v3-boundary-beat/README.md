# Proposition-local boundary-beat diagnostic

Diagnostic only. Base `3e0b634926acd2167d157292b13c695ef1bed418`. Old branches are evidence/tooling, not automatically retained semantics. No production source, existing fixture, participant, authored action, coefficient, grounding or admissibility changes.

`BoundaryBeatMeasurements` composes the preceding own-Attestation cache and existing real Orientation calculator. On a genuine causal edge it records the immediate source's last own historical Attestation event-order endpoint **at child birth**. No completed parent interval is required or used as a sample. Parent interval lists in audit records are never inserted into the child calculator.

For a child's first own Attestation, the adapter counts represented Cycle-created events strictly between that boundary endpoint and the new act, using the existing child's Horizon / entry-Committal population. It prepends that one newly completed boundary interval to the child's own act-to-act intervals. The child's sample list is not a lineage-wide list and does not contain parent samples. Later own events extend that list. Historical act rows, including replacements, retain the previous primitive's semantics; no deduplication occurs.

Existing local cache invalidation remains restricted to that proposition's own Attestation signature. A boundary position alone creates no mature calculation, Orientation, Attestation or local Chirality. The existing inverse-square lineage service, Correspondence, Closure, field projection, stored-direction resolution, grounding and participation operations remain unchanged. Origin's constitutional calibration remains the prior diagnostic's unchanged bootstrap.

Unresolved conditions stop this isolated process: an immediate predecessor with no own beat; multiple causal predecessors without a selection rule; mature all-zero CV; unsupported later-Domain comparison. These are diagnostic stops, not added production admissibility rules. A failed real contribution rolls back its transaction. A single interval, including `[0]`, remains immature/neutral regardless of its raw CV availability.

Files reuse the previous recorder and exact action replay, changing only the isolated candidate and explicit stop assertions. The single-participant test reuses its existing action scheduler and checks preserved action/target identity, Phase and Cycle sequence. It stops at the user-specified missing-beat case rather than choosing a substitute. `report.py` renders runtime evidence and archived comparators without calculating new field predictions.

Run `.github/workflows/boundary-beat.yml` on this diagnostic branch. PHP8.5 / PostgreSQL18 run the real services. The workflow restores prior fixture archives, runs primary/control diagnostics and canonical grounding/Reconcile/Bias tests, exports lossless JSON, and uploads artifacts. Extract this directory's `runtime-results.tar.gz` to inspect the raw replay.

This adapter is evidence for the supported first-Settlement prefix, not a production implementation or a fully specified resumable persistence design. No later candidate measurements are supplied after a semantic stop.
