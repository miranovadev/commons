## Approach and scope

The opt-in `PropositionLocalMeasurements` adapter extends the existing v3 diagnostic calculator. It narrows the current population to the current proposition, then reuses the existing Orientation and developmental-Cadence formulas. The current proposition's own effective votes supply its lean; its own historical Attestation acts supply the interval endpoints. Represented Cycle-entry spacing, act multiplicity, population SD, maturity threshold and formula are unchanged.

An in-memory local snapshot is invalidated only by a change in that proposition's own Attestation-state signature. Repeated calculation requests reuse it. New propositions start at local Orientation 0, Cadence 0 and Chirality 0. Origin keeps the established constitutional bootstrap and genuine creator Attestation. No local values or votes are inherited from an expressive parent.

The ordinary production lineage calculator still combines those local observations using its existing inverse-square ancestry traversal and neutral denominator mass. Production services still calculate Correspondence, Closure, projections, directions, action schemas, grounding and progression. No counterfactual API bypass or new authored action was used. The unchanged complementary reference is sampled when the target's own Attestation is observed; this history does not validate later-Domain comparative behavior.

The exact archived actor/action/payload/target sequence was replayed, rather than scheduling toward a field result. The replay would stop if an archived action became unlawful. It completed all 33 prefix and 80 continuation actions. Correspondence and Closure matched the v3 archive at every current participant boundary.

10. **Emergence:** no ordinary Commit and no Settlement → Emergence transition. Closest grounded Bias state is R from c33 onward, Tension −0.0949146, still direction-inadmissible. This is a bounded-history result, not a claim that no other lawful history could cross.
