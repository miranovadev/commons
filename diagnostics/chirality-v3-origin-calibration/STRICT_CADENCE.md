# Chirality v3 strict-Cadence bootstrap reachability

Diagnostic-only continuation. Production source is unchanged.

## Question

Assume the strongest homology with Canonical Closure v2:

```
Origin Attestation Cadence = -1
insufficient comparative Domain rhythm = 0
both Domain CV histories mature = comparative CV similarity
```

Also retain the Origin calibration refinement:

- Origin establishes polarity/direction but is not an ordinary empirical +1 lean sample.
- First developed Settlement therefore has signed Orientation in [-0.5,+0.5].
- While the Origin-side empirical Attestation rhythm is absent, strict-homology Attestation Cadence is 0.
- Hence every ordinary first-Settlement local Chirality is at most (+0.5+0)/2 = +0.25.
- Use the conservative Origin numeric Chirality seed -0.5.

Can any genuine first-Settlement Phase-7 Commit reach Emergence under those assumptions?

## Result

**No.** Under the canonical Phase structure, strict `-1 -> 0 -> comparative CV` Attestation Cadence makes the first Settlement -> Emergence crossover numerically impossible.

This is stronger than the previous recorded-C1 result.

## Why branching does not rescue the field

The generic singleton-Origin Correspondence proof allows arbitrary first-Settlement branching, but its loose shallow-depth bounds alone are not enough once +0.25 Chirality is added. The production Phase structure closes that apparent loophole.

Before Mediate, Variant routes remain structurally separate. Mediate is the first reconciliation point for Disperse children. Therefore each contributing route through structural depths 1-4 has the canonical single-route register-position sequence:

```
depth 0  Origin / third
depth 1  Signal / first
depth 2  Stance / second
depth 3  Concord / third
depth 4  Signal / first
```

Using production WL topology (two refinement iterations), Cardinal Position and the canonical edge sequence, the most direct route gives:

| depth | local Correspondence | + max local Chirality (+0.25) |
|---:|---:|---:|
| 1 | -0.2642977 | -0.0142977 |
| 2 | -0.4742166 | -0.2242166 |
| 3 | -0.4413933 | -0.1913933 |
| 4 | -0.5350935 | -0.2850935 |

Additional independent Variant routes do not turn those individual pre-Mediate observations into a shared shallow morphology; their reconciliation occurs at Mediate.

From structural depth 5 onward we do not need route-specific topology. Work Nova's deliberately generous singleton-Origin bound applies:

```
ShapeTopology <= 2/sqrt(3)-1 = +0.1547005384
CardinalPosition(d) = 2/(d+1)-1
Correspondence <= (ShapeTopology + CardinalPosition) / 2
```

Therefore:

| depth | Correspondence upper bound | + max local Chirality |
|---:|---:|---:|
| 5 | -0.2559831 | -0.0059831 |
| 6 | -0.2797926 | -0.0297926 |
| 7 | -0.2976497 | -0.0476497 |

Thus **every non-Origin position that can contribute to an ordinary Phase-7 first-Settlement Commit has local `Correspondence + Chirality < 0`**, even after granting the maximum possible strict-bootstrap Chirality +0.25.

## Origin attenuation cannot rescue it

For an ordinary Phase-7 Commit, Origin is at reverse-BFS distance at least 7.

Under the calibration bootstrap used in the preceding diagnostic:

```
Origin Correspondence = +1
Origin Chirality      = -0.5
Origin C + chi        = +0.5
```

Its maximum weighted positive contribution is therefore:

```
+0.5 / (1+7)^2
= +0.0078125
```

The head alone, even under the generous depth-7 Correspondence bound, contributes at weight 1:

```
C_head + chi_head
<= -0.2976497308 + 0.25
=  -0.0476497308
```

Ignoring every other ancestor entirely is already an overly generous upper bound, because all of them contribute negative `C + chi`.

So the attenuation numerator is bounded by:

```
-0.0476497308 + 0.0078125
= -0.0398372308
< 0
```

The denominator mass is positive, hence:

```
attenuated Correspondence + attenuated Chirality < 0
```

Canonical Closure v2 is nonpositive throughout the first Settlement against the singleton Origin committed history. Therefore:

```
Correspondence + Chirality + Closure < 0
Tension < 0
```

and first Settlement cannot cross to Emergence.

## Consequence

The exact Closure-style Attestation Cadence bootstrap:

```
-1 -> 0 -> comparative CV
```

is semantically elegant but creates a structural bootstrap cycle for Chirality:

```
a second developed Domain rhythm is required for nonzero comparative Cadence
but
a first Domain crossover is required to create that second developed Domain rhythm
```

With Canonical Correspondence v2 and Closure v2 held fixed, Orientation's restored [-0.5,+0.5] freedom is not numerically sufficient by itself.

Therefore, if the first Settlement -> Emergence crossover remains required, **Attestation Cadence needs a genuine first-rhythm formation semantic before ordinary adjacent-Domain CV comparison becomes available**, or another held premise must change.

No formation formula is selected here. This diagnostic only establishes that strict homology is insufficient.
