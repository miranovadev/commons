against the specified singleton, +1-lean Origin reference.

The ten-Commit ceiling was superseded by the requested analytical stop. Three
Commits were retained to verify progression, polarity equivalence and the first
negative cumulative Closure value. No post-Emergence state or mature Cadence/Bias
decision exists on these trajectories.

## Correspondence bound

This bound concerns the initial Origin-only complementary reference, before any
branch has developed a new Emergence Domain. Its assumptions are:

1. The reference morphology is the single Origin node, at depth 0/lateral 1.
2. Developed current morphology consists of genuine causal ancestry connected to
   that Origin. Every nontrivial morphology node has an incident internal edge.
3. Depth-one positions have Origin as their sole causal parent. Genuine
   Distinguish creates these; ordinary Order requires a non-Origin Bias source.
4. No developed foreign Domain supplies a placement-only isolated node. Before
   the first crossover, the only Emergence proposition is Origin; it cannot
   supply an expressive Phase-3/5 homologous operand. First-Settlement branching
   and Reconcile ancestry are permitted by the bound.

These conditions were checked against the recorded prospective morphologies.
The proof is not a claim about later Domains, arbitrary imported graphs, or an
Origin reference changed by additional noncanonical bootstrap development.

### 1. Shape Topology has a finite upper bound

Production Correspondence uses WL features from iterations 0, 1 and 2. Singleton
Origin supplies one feature at each iteration. In a nontrivial connected current
morphology, every node has a neighbor; neither refined singleton-Origin feature
can match. Only its iteration-zero register label can overlap.

The normalized reference vector has three unit coordinates. A current vector
supported on at most one of those coordinates has cosine similarity at most
`1/sqrt(3)`, by Cauchy–Schwarz. Therefore:

`ShapeTopology <= 2/sqrt(3)-1 = 0.1547005384`.

This is deliberately generous: it allows the best possible register counts and
refinements. Actual developed topology can score substantially lower.

### 2. Cardinal Position penalizes unmatched depth rows

If a head has Domain depth d, its causal ancestry contains an occupied row at each
integer depth 0 through d. At depth 0 the Origin coordinates match (+1); all d
other rows lack a reference row (-1). Sibling gaps cannot improve those unmatched
rows. Thus:

`CardinalPosition = 2/(d+1)-1`.

With the unchanged equal weighting, every local value at d>=2 satisfies:

`C_local <= 1/sqrt(3)-1+1/(d+1) <= -0.0893163975`.

A depth-one position has a two-node morphology. Even granting both nodes Origin's
register (more favorable than actual Distinguish), its maximum local score is:

`C_local(depth 1) <= 1/sqrt(6)-1/2 = -0.0917517095`.

So every developed non-Origin local Correspondence value is negative under these
conditions. Origin alone retains its constitutional raw +1.

### 3. Attenuation cannot rescue an ordinary Commit

An ordinary Commit has d>=2. The unchanged inverse-square ancestry weights are
positive; if traversal stops at earlier Committals before reaching Origin, every
included value is already negative.

If Origin is included, its reverse-BFS distance D is at least the head's structural
depth d. Its contribution is at most `1/(d+1)^2`.

For d>=3, even discarding every other negative ancestor contribution gives a
negative numerator:

`1/sqrt(3)-1+1/(d+1)+1/(d+1)^2 <= -0.1101497308`.

For d=2, the shortest two-edge path also includes a depth-one ancestor at distance
1. Even the relaxed numerator bound is negative:

`(1/sqrt(3)-2/3) + (1/4)(1/sqrt(6)-1/2) + 1/9 = -0.00114321375`.

Additional ancestors contribute negative values. Dividing by positive total mass
preserves the sign. Rounding to seven decimal places does not turn a nonpositive
value into a positive one. Ordinary Commit Correspondence is therefore negative
(or at most nonpositive at a hypothetical rounding boundary).

### 4. Chirality and Closure cannot offset that sign

Under the requested singleton +1-lean Origin reference, displacement Orientation
is in [-1,0]. Unavailable Cadence supplies neutral mass, so local Chirality is in
[-0.5,0]. Origin's candidate Chirality is 0. Positive attenuation weights preserve
`X<=0`.

Closure remains canonical. Before any Emergence crossover, only one committed
Emergence observation exists. Comparative Committal Cadence and Lateral are
immature and 0. The first Settlement Commit has K=0. For its nth same-branch
Settlement observation n>=2, full-history Depth is `-1+2/n`, hence
`K=-1/4+1/(2n)` (subject to the existing rounding). Therefore `K<=0`.

Consequently `C+X+K` cannot be positive. Primitive or retained directions do not
add positive numeric mass to this sum. Repeating Settlement Commits does not
remove the obstruction while these reference/topology conditions remain fixed.

No singleton or all-zero CV rule was chosen. The candidate defers comparison when
one side has no intervals, which is sufficient throughout these runs because
Origin's sequence remains empty. If both sides acquired interval populations,
the helper stops on an unresolved singleton threshold or zero-mean CV rather than
assigning a convention. It would apply ordinary direction agreement only for two
genuine measurable components.

The smallest semantic decision is now whether the proposed displacement plus
neutral-immature-Cadence Chirality is intended to make this Origin-referenced
bootstrap unable to cross. If a finite crossover is required, at least one of the
held premises must be reconsidered; changing maturity handling alone has not
supplied the missing positive numeric contribution. No such change is proposed
or implemented here.

## Ordering/persistence requirement

Fresh single-process callbacks record Cycle creation and each individual
Attestation occurrence. Their observed act order is checked against the real
contribution-ledger sequence. Replacement acts remain separate, and entries are
counted only within the production lineage's represented basins/Horizon.

Production implementation would require durable common ordering for Cycle-entry
and Attestation events within a substrate (or equivalent persisted causal
watermarks). It must support replay of zero-entry bursts and later reconstruction
without timestamps or ordering acts by their owning Cycles. This diagnostic adds
no production persistence and proposes no second-resolution timestamp solution.
